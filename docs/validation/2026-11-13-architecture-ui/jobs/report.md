# 本地任务恢复与运行时生命周期

2026-11-14。任务缓存独立保存于 `jobs.sqlite` v1；原始资料库保持 schema2。任务仅记录 source ID/revision、模型代际、有限状态、次数、重试时间与随机租约，不复制正文/音频/向量，不调度付费云调用。`jobs-owner.sqlite` 的SQLite写锁负责跨实例调度所有权，同进程第二个Storage也不会撤销旧租约；竞争者保留原始资料读写并暂停自动任务，之后可重开。进程退出自动释放锁。已知缓存最多16384页，SQLite连接缓存512KiB；空间或格式错误暂停自动调度，原文与手动操作仍可用。

## 自动验证

- 宿主真实SQLite：源转写提交后、任务确认前重启，不重复处理；编辑/删除/模型换代使旧租约失效；未来v2缓存原字节保留；损坏缓存不阻止源记录保存；短暂错误最多3次，分别延迟1秒/5秒。
- 启动：最小草稿恢复先执行，完整孤儿音频维护延后；逐文件重新核对引用，使用录音锁和媒体屏障。采集中和备份租约期间跳过维护，后续空闲可重试；正常引用音频保留。
- 模型目录不可用时保留记录/关键词能力并提供 modelNotice 状态供页面显示；源资料库自身损坏或未来版本仍按原边界安全拒绝，不伪装为空库。
- 停止或丢弃录音会发布不改变内容代际的状态事件，唤醒后台调度；无需靠新增/编辑记录触发。对应“无编辑停止后任务仍停住”回归曾失败，修复后通过。
- 推理关闭：立即拒绝未完成调用者与排队任务，`close()` 等待正在执行的action的finally完成；64任务背压、前台优先、采集暂停及迟到结果拒绝回归保留。当前模型仍每次调用加载并释放，没有新增常驻模型。
- Android API36 ARM64模拟器，独立包 `app.nianxia.nianxia.test`，非调试release/AOT：转写源提交后重开无重放、旧租约失效、新任务revision正确、在途action释放后close才完成、source schema2。见 `android-release.json`。结果中的合成Transcriber用于验证任务/存储协议，受控action用于验证队列join，并非真实ASR质量或真实native模型释放的实测。

最终宿主门禁：`bash tool/check.sh`，31项Python测试、静态分析无问题、278项Flutter测试通过。Android release最终结果包含停止采集唤醒、同进程竞争实例不撤销租约。诊断仅保存模型代际的稳定28位摘要和0–3尝试次数，不保存模型路径或原文。

## 限制

正式包未安装，正式数据未读取；runner确认正式包路径在前后保持一致，无法据此证明正式数据内容散列。完整Xcode/iOS及Magic8/iPhone17不可用；真机模型复用收益、内存警告、系统回收和平台录音质量验收保留。Native capture/default encryption仍受各自门禁约束，不因本阶段通过而切换。

任务库发生已知错误后本次打开不反复重建/删除它；重开或手动重试可恢复可选能力。跨源库与任务库没有共享事务，恢复靠已提交源结果与版本匹配。新恢复的音频不会自动覆盖用户编辑正文。完整维护因活动录音/媒体租约而跳过的部分在后续维护或重开时处理。
