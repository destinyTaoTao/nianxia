# 页面与数据管理验收

2026-11-14；对应 R4。使用已批准的中性主题、顶部查找/写文字、底部单一录音入口；正文17、辅助14逻辑尺寸。搜索页面只接收每页最多40条摘要，详情按ID读取最新原记录；内容变化重新查找，索引状态变化不清空已显示结果。

## 已执行的主机验证

`bash tool/check.sh`：304项Flutter测试、32项Python工具测试通过，静态分析无问题。涉及以下行为：

- 原生录音界面收起不取消；返回同一会话，保存状态必须来自原始资料提交；父记录删除后明确确认转为独立记录。胶囊与详情追加共用注入的原生owner；未通过平台门禁的普通应用保持兼容路径。
- 页面命令绑定会话ID，旧页面不能停止新录音。耗时语音查询不持有录音控制锁；查询清理不能删除同ID的已恢复原音频。查询切后台先停止采集，返回后主动识别、编辑、确认查找。
- 待恢复资料按受管ID分页，可试听、明确标注未加密的导出及确认丢弃；未来格式只读保留，链接路径不被当作受管原文件。原生失败/零PCM片段进入恢复目录，不自动变成记录。丢弃用持久化标记与独立native确认，失败后不重新导入。
- 新备份密码至少12字符、精确二次确认，旧备份密码不套用新长度条件；保留空格和Unicode，不开启键盘学习或自动填充。UI字节缓冲使用后尽力清零；Dart不可变字符串不承诺内存擦除。
- 密码完整备份、可读明文导出及旧明文恢复分别展示；密码错误/损坏使用统一错误；显示恢复冲突统计。文件选择器返回前取消后不能继续导入，取消/离开信号传递到后台操作。
- 诊断导出先预览时间、事件数、大小和封闭字段；分享回调只表示交接，不宣称外部文件已经保存。模型缺失和可选任务缓存不可用有降级提示；原始记录仍可读写。

NativeCaptureSession 的14项JVM测试通过，包含已认领片段的显式丢弃、持久化清理失败与幂等取消。Android API36 ARM64模拟器的独立Profile/AOT集成通过（`android-profile.json`）：真实AudioRecord采集106540字节WAV，未保存前仅有两条合成文字，收起/返回保持同session，停止后原始库提交第三条记录，再由摘要查找返回一条合成结果。没有转写采集到的环境音频。测试键盘在页面创建前注册，仅用于输入合成查询；该结果不等于真实系统IME验收。拒绝活动会话期间结束测试工作区。

## 隔离与证据边界

独立包 `app.nianxia.nianxia.test`；测试原生owner只接受运行UUID，目录固定在经过身份核验的私有cache下，不接受任意路径；活动会话存在时拒绝切换/结束工作区。每次运行只创建、删除自己的合成笔记与录音夹具。截图只含合成文字，不包含已有测试库或正式数据。

普通应用未默认启用新native capture或密码加密：Gate-C/B仍缺Magic8、iPhone17和完整Xcode证据。Android模拟器不能替代真机锁屏、系统回收、通话/蓝牙、热量、电池或麦克风自然语音质量验收。iOS原生返回、VoiceOver和实际玻璃材质均未验收；R5继续处理可独立实现的平台偏好和实色降级。
