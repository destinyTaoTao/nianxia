## 行为与修正

- 新安装无偏好默认跟随系统，已有浅／深／系统选择优先保留；首页移除快捷切换，设置内直接显示三个单选项。
- 只有真实偏好写入成功才切换；保存中禁用选择，失败保留原选择并提示重试。沿用SQLite保序语义，未增加调度器。

- 没有新增生产依赖、数据迁移、生产诊断或内容遥测。主题工厂及存储实测成本较小，因此没有引入缓存或改存储架构。

## 验证

`bash tool/check.sh` 最终通过：37项Python工具测试、`flutter analyze` 无问题、341项Flutter测试通过。新增9项主题App/控件测试使用真实临时Notebook，覆盖默认系统与系统变化、旧选择、成功首帧根背景/正文颜色、同亮度偏好同步、保存故障、连续调用与重开、320逻辑像素双倍字体及可点击尺寸、保存中重复输入。

首次完整门禁有两项设置测试失败：新增外观区域改变了恢复按钮位置，旧测试滚动后未等待布局，tap坐标落在屏外。测试改为先确保按钮可见并等待稳定，保留原有失败／取消／互斥／资料不变断言；两项单独复测与最终完整门禁均通过。

独立只读审查两轮未发现Critical/Important。其采样窗口建议已修正，测量语义已明确；自检、独立审查和设备验收分别记录，没有用其中一种替代另一种。
