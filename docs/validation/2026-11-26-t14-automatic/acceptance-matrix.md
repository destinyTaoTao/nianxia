## 接入与授权依赖

1. 先验普通默认路径，不为验收自动启用原生后台录音、密码备份或玻璃。iOS实验原生后台录音/加密接入还需各自门禁，拿到设备不等于功能已接通。
2. 真机接入需设备解锁、信任、调试/签名授权。来电、撤权、音频路由、系统日历、屏幕阅读和自然手势需人工配合；采样与汇总可自动进行。
3. 自愿非敏感自然口述、独立标注查询/无答案集待准备。云端测试Key和预算需另行明确授权，不要求在聊天里粘贴Key。
4. 性能目标：已授权前台点击至采集P95≤500ms、停止至保存≤1s、30秒录音转写≤15s、1000条短记录热查询≤1s。冷启动/语音查询单列，先约20次基线，再扩展尾部；本次构建和主机结果不替代这些目标。
5. 两端实际安装与已知限制、两周试用仍待完成。当前为Debug签名Release，不作正式分发认证。
