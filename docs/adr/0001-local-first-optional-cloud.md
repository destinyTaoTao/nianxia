# 本地优先，云端自愿增强

用户已确认第一版在模型就绪后支持离线录音、转写、文字与语音查找；云端仅提供可选的精整理，默认关闭，只发送用户主动选中的文本，失败不影响原始记录。首版不内置生成式大模型，以减少模型体积、峰值内存与双平台适配成本；后续增加本地生成能力需独立评估，不提前建设通用模型平台。

产品使用“本地优先”描述数据边界，不能宣称全部 AI 处理都在本地或数据永不离开设备。用户进一步确认首版自带 API Key，凭证仅存设备安全存储，不建设产品云端代理；模型首次下载，之后离线使用。服务商与模型版本实施前核验；可选云端能力不等于用户授权自动上传笔记库、音频或查询。

此决定取代早期方案中“所有整理均在本地、正文一律不发送给第三方 AI”的限制。项目规则已同步，其他隐私与数据可靠性约束继续有效。
