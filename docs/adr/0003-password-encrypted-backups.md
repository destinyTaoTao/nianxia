# 优先加密完整备份，本地资料先落实系统保护

2026-11-13，用户确认首版优先提供密码加密的完整备份；本地数据库和音频先验证并落实系统文件保护、应用隔离和自动备份排除，暂不增加独立应用解锁密码。相比同时引入数据库、音频与备份的应用层加密，此范围优先保护更容易离开设备的完整副本，减少设备内密钥管理与锁屏录音之间的复杂度；不宣称能防止已解锁设备上的他人访问、root/jailbreak 或受控进程读取。

备份密码由用户保管，不建设产品密钥托管；忘记密码无法恢复该加密备份。诊断不包含正文、音频或密码；完整备份因恢复用途必须包含用户资料，两者不能使用同一内容排除规则。此决定确定保护范围，不锁定密码容器、依赖或 KDF 参数；具体选择须经过双平台资源测量、互操作和损坏输入验证。

现有未加密 ZIP 备份仍须兼容导入。旧文件不会因应用升级自动变为加密。用户进一步确认保留独立的“导出文本与音频”入口并明确提示未加密，完整备份默认密码加密；两类导出分别表达可阅读/播放与完整恢复的用途。
