# 100,000 条离线检索验证

日期：2026-11-13。对象：真实 SQLite、100,000 条中文短文本、36 字符 UUID、每条 512D 稠密 Float32 向量。向量为固定种子的 100 个簇；12 个独立查询各重复 5 次，与全部源向量的精确余弦 Top10 比较。**Recall 是近邻算法召回率，不是中文语义理解准确率。**

运行环境：macOS ARM64、10 核、Dart 3.13.7 AOT、系统 SQLite 3.51.0。造数、精确基准和测量分进程，测量时不并行编译/运行测试。仅使用有专用标记的临时库，无音频、云服务或真实用户内容。测量不包含 Flutter UI、BGE/ASR 推理、真实手机或磁盘清缓存后的冷 I/O。

完整后台准备实测 **987.890 秒（16.46 分钟）**，包括从空缓存建立文本索引和 HNSW、以及上述早期查询负载；首次查询已在 2.21 秒返回。图的构建参数为 M=12、construction ef=80。此次构建时的查询实现仍为 upper=1；之后只修查询上层导航，**没有修改 add、向量、邻接图、缓存格式或构建参数**。因此保留本次冷建时间/体积，用同一完成图单独复测最终查询算法；不是伪装成第二次从零建图。

RSS 是 **整个独立测量进程**，包括 VM、SQLite、native/heap 页面；不是 Dart heap、缓存载荷或完整 App 的内存。构建和最终查询分进程，分别报告各自峰值，不把旧查询算法的进程峰值冒充新算法整体峰值。4 MiB 的图向量工作集预算不等于整个进程只占 4 MiB。

`dbstat` 观察的主要空间：节点表 391.6 MiB、倒排辅助索引 161.7 MiB、倒排主表 157.5 MiB、文档表 23.9 MiB。当前 4 KiB 页面下，节点表约 175.6 MiB 是页内空闲；512D 载荷与邻接数据的页装填仍有优化空间。见 [完整布局](index-layout.json)。这不是无限容量或最优磁盘布局的承诺。

十万条全命中仍返回全部关键词结果，时间和结果内存随命中数增长；本轮没有引入搜索结果分页。大结果跨 isolate 传输、真实 UI 呈现、不同正文长度/模型/设备的峰值仍需单独验收。

## 发现并修复的召回问题

1. upper=1、底层 ef=200 时 Recall@10=0.9167；第 6 号查询的 Top10 全部遗漏，其余 11 个查询完整召回。
2. 仅将底层 ef 提到 512，结果仍为 0.9167，说明不能靠更大的底层候选预算修复。
3. 真实图的逐层路径检查显示：目标簇 42 的查询，在 upper=1 时止于簇 51（余弦约 0.071）；upper beam=8 可以在第二层进入簇 42（余弦约 0.963）。
4. 添加可复现的小图回归，先失败（应返回 target，实际 local），再让查询保留上层 8 个候选。构图保持不变；相同十万节点图、底层 ef=200 复测达到 1.0。

原始 [冷建/失败结果](cold-upper1.json)、[单纯扩大 ef 仍失败](warm-upper1-ef512.json)、[最终上层 beam 结果](warm-upper8-ef200.json) 和 [全命中结果](all-match-keyword.json) 均保留，不删除失败数据。结构检查也发现 5 个节点不能从 entry 沿图边到达；它们未进入这些查询的 Top10。这进一步说明 ANN 不保证所有输入全量召回，关键词、源数据和缓存重建路径仍必须保留。

## 复现

```sh
dart compile exe tool/benchmark_search.dart -o /tmp/nianxia-search-benchmark
/tmp/nianxia-search-benchmark --records 100000 --dimensions 512
```

普通入口自动创建标记临时库，依次 seed/gold/measure；成功后清理它创建的夹具并保留 JSON 报告。cold measure 拒绝已有 sidecar。`--phase warm --home <已标记夹具> ... --ef 200` 仅用于相同完成图复测，不能用于声称从零构建；`--phase wide` 是独立的全命中进程。失败保留标记夹具和测量数据用于诊断。源码 [benchmark_search.dart](../../../tool/benchmark_search.dart)。

本轮最终门禁和 Android/数据安全结果见 [架构审查记录](../../architecture-review.md)。实际手机、iOS 完整构建、真实中文人工标注集、长正文/大量结果及电耗均未由此验证。
